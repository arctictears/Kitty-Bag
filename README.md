# Kitty-Bag
you play as a kitty in a bag where you try scavenge the docks for common and electric fish (I later realized eels exist) collect fish to win. Controls: A + W/ left/right arrow, space to jump. all music, art and code made by me. using piskel, LMMS and Unity.
the itch.io play link: https://arctictears.itch.io/kitty-bag
the Github link: https://github.com/arctictears/Kitty-Bag
